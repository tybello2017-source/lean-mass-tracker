LEAN MASS TRACKER — PWA V1

What is included
- Mobile-first daily dashboard
- Meal database imported from the supplied Excel tracker
- Automatic calorie and protein totals
- Breakfast/snack/lunch/dinner/other meal logging
- Manual calorie/protein override via custom meals
- Serious Mass entries from your tracker
- Workout A/B/C with Friday and Sunday make-up flexibility
- Per-exercise weight/reps logging
- Weight, waist, sleep and energy logging
- Progress chart
- Offline storage on the device via localStorage
- JSON backup/export and restore/import
- PWA manifest + service worker for offline use after first load

IMPORTANT: An iPhone cannot install a PWA from a local ZIP/file. The folder must first be hosted on HTTPS.

Easy deployment options (no Mac required)
1. GitHub Pages: upload these files to a repository and enable Pages.
2. Netlify Drop / Netlify: deploy this folder as a static site.
3. Any HTTPS web host that serves static HTML/CSS/JS.

After the site is online on iPhone
- Open the site in Safari.
- Tap Share.
- Tap Add to Home Screen.
- Choose Open as Web App / Add.

Data privacy
V1 stores your logs locally in the browser on the device. There is no server database or login. Use Settings > Export backup periodically. Clearing Safari site data can erase local app data.
